# Retired custom map/navigation reference

Archived on 2026-11-05. These documents, old normative vectors, provider setup and Kolkata dataset describe the removed implementation. They are historical evidence, not current setup instructions or supported endpoints. New turn guidance is only planned in the active turn-by-turn documents.

The Kolkata dataset retains its original OpenStreetMap ODbL licence, attribution and provenance in `kolkata-dataset/`. It is no longer bundled in the mobile app or firmware. No archived source or data is included by a build target. Source removed in this change is also preserved in the verified local source backup recorded in the removal record and in Git history. Relative links inside historical documents retain their original context; consult the active docs for current behavior.
