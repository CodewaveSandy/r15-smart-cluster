# Chakra Petch Bold Italic

Angular, forward-leaning numerals for speed (Street/Track) current-lap timer and gear/neutral. This is an R1M-inspired treatment, not Yamaha’s factory typeface or an exact reproduction of the AI concept.

Source: https://github.com/google/fonts/tree/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/chakrapetch
Pinned Google Fonts revision: `47d54ca1ebb14fd864695f1d39dc734f39017c33`. Files bundled unmodified. License: SIL OFL 1.1; see [OFL.txt](OFL.txt).

Regenerate the role-specific 4-bit LVGL subsets with `bash scripts/generate-fonts.sh`. TTF sources are build inputs, never runtime dependencies. After each conversion, `scripts/embolden-font.py` applies a subtle half-pixel cardinal coverage expansion within existing glyph bounds. Advances, kerning and allocations stay unchanged; the original licensed TTF is unmodified. Never run this pass twice on the same generated output. Current-lap size is 74 px to retain separation from the secondary speed.
